# Contributing

Found a bug in a skill: a broken reference path, a trigger that misfires, an output format that doesn't land? Open an issue or a pull request.

What we merge: fixes to skill mechanics (routing, triggers, formats, file paths) and improvements to how faithfully a skill applies the source frameworks.

What we don't merge: changes to the frameworks themselves. The frameworks come from the books; the books are the source of truth. If you think a framework is wrong, that's a conversation, not a PR. Email hello@productled.com.

When adding or editing a skill, match the house pattern: a `SKILL.md` with a trigger-rich description, a numbered "How to work" that routes to `references/`, a concrete output format, and quantified language throughout. Run your description against the existing ones. If it could trigger on the same question as another skill, tighten it.
