# Template: 5-Star Offer / Homepage (Component 4)

Produce actual copy, not descriptions of copy. Every claim quantified ("average 12-minute setup", not "easy setup"). Calibration: PromoTix's rewrite delivered +40% signups on identical traffic.

## Worksheet first (show your work)

**Core offer (all three pillars, no exceptions):**
- **Result** (tangible outcome, from the User Component's top 3): …
- **Advantage** (why 5–10× better; must reinforce a moat; passes "why does it matter?"): …
- **Assurance** (names the top objection, ROI / setup / support / security, and kills it): …

**Enhancers (pick up to 3; authentic only):**
- Scarcity (real capacity limits only, artificial scarcity doesn't work): …
- Urgency (limited-time / exploding / cohort / bonus-based): …
- Bonus (ties to an unresolved user challenge; Keap's free automation audit is the bar): …

## The page (write all five sections as final copy)

### 1. Hero
- **Tagline**: communicates the Result. (PromoTix: "Built for event creators" → "Sell more tickets without insanely high ticketing fees.")
- **Sub-copy**: reinforces, prompts action, includes a number.
- **CTA**: action-first verb, specific. ("Ticket My Event" beats "Sign Up.")
- **Visual**: one line of art direction.
- **Social proof**: the most credible signal they actually have.

### 2. Problem
Structure: **Spiky point of view → top challenges → agreeable viewpoint.**
Test: would this section work as a LinkedIn post? If it would fall flat, it's not spiky enough. Sharpen before proceeding.

### 3. Solution
"How it works" in ≤5 steps, each step restating progress toward the Result.

### 4. Risk Reversal
List the real reasons people don't sign up (ask the user for objections their team actually hears). Counter each with: guarantee / endorsement / review / logo / user count / demo / certification.

### 5. CTA
Answer: why now · what they can do immediately after signup · is it risk-free · the next step. **No new information here**: this section closes, it doesn't introduce.

## Ship instruction

Deliver with an A/B plan: run the new page against the old for one week (PromoTix's playbook), then roll the winner to 100%. A 7/10 page live this week beats a 10/10 page next quarter.
