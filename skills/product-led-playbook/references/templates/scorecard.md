# Template: ProductLed Scorecard / Metrics Tree (Component 7)

Output of the True North Framework. Hard rule: less is more. ProductLed's own first scorecard had 36 metrics for a team of 5 and went nowhere. Ten metrics, each with an owner, or it's not done.

## 1. North Star Metric

Propose ONE, built from three parts: **quality** (an action in the product) × **quantity** × **frequency** (cadence matching real usage: Slack weekly, Instagram daily).

Derivation: start from their Value Metric; if stuck, from their KUI (Slack: 2,000-message KUI → messages/week NSM). Cross-check both angles: what do highest-LTV customers do consistently (company view) and what do best-retained users do consistently (customer view)? State why customer and company both win when it goes up. Airbnb's "nights booked" is the calibration.

## 3. PQLs: only after 1+ month of scorecard discipline

PQL = Ideal User Profile + Setup + First Strike + KUI hit → 30–50% upgrade odds. Upgrade the GTM rows: Signups → Ideal Signups; KUI → PQLs; Upgrades → Ideal upgrades. If the user asks for PQLs before they have a working scorecard, tell them no and why.
